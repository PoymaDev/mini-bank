# "Мини-Банк" на Spring Boot
Привет! Меня зовут Арсений и это мой первый проект, который я постарался написать за первый месяц изучения Spring Boot и Java Backend.
Здесь реализована основа для работы цифрового банка: создание счетов, проверка баланса, транзакционный перевод средств, а также глобальное отлавливание исключений.

## Использованные технологии
* **Язык:** Java 25
* **Фреймворк:** Spring Boot 3.4
* **База данных:** PostgreSQL 17
* **Работа с БД:** Spring Data JPA + Hibernate
* **Контроль версии:** Git

## Как проект устроен изнутри
Код разделён на три классических слоя:
1. **Контроллеры (`BankController`)** - "дверь" приложения, принимают запросы от пользователя из браузера или терминала в формате JSON, проверяют и отдают их ответ.
2. **Сервисы (`BankService`)** - "мозг" банка, проверки, хватает ли денег на счете, сами списания.
3. **Репозитории (`AccountRepository`)** - "руки" банка, которые ходят в базу данных PostgreSQL, сохраняют туда новые строки или достают существующие счета.

## Что также реализовано в плане логики и безопасности:
* **`BigDecimal`** - для баланса счетов строго используется тип `BigDecimal`
* **Защита данных (DTO):** контроллер никогда не отдает наружу чистый объект из базы данных. Специальные классы (`AccountDTO`, `CreateAccountRequestDTO`) прячут от пользователя системные параметры.
* **Валидация данных на входе:** с помощью аннотаций `@NotBlank` и `@PositiveOrZero` сервер автоматически проверяет запросы.
* **Умный перехватчик ошибок (`@ControllerAdvice`):** Если пользователь делает что-то не так (например, переводит деньги на несуществующий счет), сервер не падает и не выдает белую страницу ошибки 500. Класс `GlobalExceptionHandler` ловит исколючения и отдает JSON со статусом ошибки 400.
* **Переводы (`@Transactional`):** Метод перевода денег защищен транзакцией.

## Существующие и работающие на данный момент ручки

### 1. Создание счета (Принимает JSON в теле POST-запроса)
* **`POST /create`**
* Пример тела запроса:
  ```json
  {
    "accountNumber": "40802000",
    "ownerName": "Alex",
    "initialBalance": 50000
  }
  ```

### 2. Проверка баланса (Поиск счета по номеру в URL)
* **`GET /{number}`** (например: `http://localhost:8080/40802000`)

### 3. Перевод денег между счетами
* **`GET /transfer?from=40802000&to=40809999&amount=15000`**
